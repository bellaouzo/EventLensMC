# Architecture Decision Records

Record significant technical decisions here before implementing them.

## When an ADR is required

- Adding NMS or `paperweight-userdev`
- Adding a Java agent or bytecode transformation
- Adding network telemetry or external reporting
- Adding a database for trace storage
- Publishing a stable public API
- Converting to a multi-project Gradle build
- Changing privacy defaults or materially raising trace limits
- Expanding supported Paper version range

## Format

Create `docs/adr/NNNN-short-title.md` with:

1. **Status** — proposed, accepted, rejected, superseded
2. **Context** — problem and constraints
3. **Decision** — what was chosen
4. **Consequences** — benefits, risks, test impact
5. **Alternatives considered**

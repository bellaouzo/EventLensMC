# eventlens-fabric

Fabric client mod for EventLens. Optional companion to the Paper plugin.

Uses `eventlens-mod-common` and `eventlens-core` for trace sessions and JSON export.

Supports `/eventlens` (alias `/el`) with clickable status, listeners, and trace start/stop/list/view/export. Traces client events such as use item/block/entity, attack, chat, screens, join/disconnect, move, and tick.

Build: `.\gradlew.bat :eventlens-fabric:build`
